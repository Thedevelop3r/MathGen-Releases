# MathGen

A free equation editor for Windows, made for students and teachers. Type
equations with the keyboard and toolbars, then put them into Word, PowerPoint,
OneNote, Google Docs or Overleaf. It works offline, needs no account and
collects no data.

## Download

Get the newest version from the **[Releases page](https://github.com/Thedevelop3r/MathGen-Releases/releases/latest)**:

- **`MathGen-…-x64.msi`**: the installer. Adds MathGen to the Start menu and
  opens `.mgq` equation files. Uninstall from Settings → Apps.
- **`MathGen-…-portable-x64.zip`**: no installation and no administrator
  rights. Unzip anywhere (a USB stick works) and run `mathgen.exe`.
- **`SHA256SUMS.txt`**: checksums, to check that a download is complete and
  unchanged.

Needs Windows 10 or 11 (64-bit).

If Windows shows **"Windows protected your PC"**, choose **More info → Run
anyway**. Windows shows this for new programs that few people have downloaded
yet. A Microsoft Store version, which installs without this warning, is coming.

Press **F1** in MathGen for the Quick Start guide.

## What it does

- Fractions, roots, scripts, brackets that grow, sums, integrals, limits,
  matrices, accents, boxes, arrows and aligned multi-line equations.
- Textbook-quality typesetting (New Computer Modern fonts, OpenType MATH).
- Copy into **Word, PowerPoint and OneNote** as an editable equation, into
  **Google Docs** and web apps as a sharp picture, or as **LaTeX** or
  **MathML**.
- Type or paste LaTeX; export PNG, SVG and EMF.
- Ready-made formulas for algebra, calculus, statistics, matrices,
  trigonometry and geometry.
- English and Urdu interface, light and dark themes, large interface sizes,
  customisable shortcuts, full keyboard use.
